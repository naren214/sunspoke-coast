# Opening artwork

`public/home/coast-keyart.webp` is the locally bundled 1672 × 941 opening artwork (151,710 bytes). `coast-keyart.png` retains the generated source. Generated with the built-in image generation tool on 18 November 2026, using the project's refined Cayenne image as a visual reference. The image is promotional artwork; the actual game replaces it with its live rendered car preview after startup.

## Art direction / prompt

Create a cinematic wide promotional background for Sunspoke Coast, a stylized 3D browser driving game. Use the supplied refined Cayenne as the reference for the car: a midnight-teal Porsche Cayenne with brushed-metal wheels, red rear lights and gold calligraphic NAREN on the back. Show it from a rear three-quarter angle on the right side of a sweeping beachfront boulevard. Turquoise sea, gentle surf and beach on the left, terraced hotels, palms and a warm coastal skyline on the right. Golden-hour sunset with coral clouds and amber highlights, rich midnight teal shadows. Match the polished stylized game aesthetic. Leave the left third calm, dark and open for real HTML typography and controls. Widescreen composition. No interface, buttons, headline, watermark or text beyond the car's NAREN signature.

The source is converted to WebP at quality 87, method 6. Both source and optimized artwork are included in the source archive; the game uses only the optimized WebP. All runtime assets are local.
