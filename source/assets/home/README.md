# Opening artwork

The bundled 1920 × 1080 `public/home/coast-keyart.webp` comes from the game renderer at the beachfront starting position. It uses the finished Sunspoke GT in golden-hour lighting with a low rear three-quarter camera. The matching capture is retained as `source/assets/home/coast-keyart.png`. The title screen fades from that image to the live scene after startup.
